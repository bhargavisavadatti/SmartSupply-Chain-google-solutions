# SmartSupply Chain
### Google Solutions Build with AI — Hackathon Submission

## Problem Statement
Smart Supply Chains: Resilient Logistics and Dynamic Supply Chain Optimization

## Our Solution
SmartSupply Chain is an AI-powered web platform that detects supply chain 
disruptions and instantly calculates their financial impact using Google 
Gemini AI, then recommends the most cost-efficient action.

## USP
We don't just detect disruptions — we quantify exactly what they cost 
you and tell you the smartest financial move next.

## Tech Stack
- Frontend: HTML, CSS, Vanilla JavaScript
- AI: Google Gemini API
- Database: Firebase Firestore
- Hosting: Firebase Hosting (Google Cloud)
- Charts: Chart.js

## Features
- Live shipment risk dashboard with real-time Firebase updates
- Gemini AI disruption analysis and plain-English summaries
- Automated financial impact calculator (penalty + holding costs)
- Smart rerouting recommendations with cost comparisons
- 30-day cash flow forecast with disruption impact overlay
- Decision logging to Firebase Firestore

## How to Run
1. Clone this repository
2. Open firebase_supply.js and paste your Firebase config
3. Set your Gemini API key in firebase_supply.js
4. Open index_supply.html with Live Server in VS Code
